# The Poki999 포트폴리오

이 프로젝트는 React와 Next.js, 그리고 Tailwind CSS를 사용하여 제작된 개인 포트폴리오 사이트입니다.

## 주요 특징
- **다크모드 지원**: 독특하고 세련된 테마 전환 스위치를 통해 다크/라이트 모드를 지원하며, 사용자 설정이 브라우저에 저장됩니다.
- **반응형 디자인**: 다양한 화면 크기에서 최적화된 사용자 경험을 제공합니다.
- **깔끔한 프로젝트 구성**: 프로젝트별 상세 내용과 소개를 관리하기 쉽게 설계되었습니다.

## 기술 스택
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Theme**: Styled-components (애니메이션 토글 스위치 구현)

## 시작하기
1. 프로젝트를 클론합니다.
2. 의존성을 설치합니다: 
   ```bash
   pnpm install
   ```
3. 개발 서버를 실행합니다:
   ```bash
   pnpm dev
   ```
4. 브라우저에서 `http://localhost:3000`에 접속하여 확인합니다.
